# +90 Flutter Starter (0.1)

This is the first real Flutter source-code foundation for the +90 football app.

## Included
- Dark + gold visual identity
- Arabic / English language toggle
- RTL / LTR direction handling
- Home screen and bottom navigation
- Placeholder sections for Matches, Fantasy, Community and Profile
- Clearly marked sample fixtures (not live data)

## Run it
1. Install Flutter SDK on a computer.
2. Create a Flutter project: `flutter create plus90`
3. Replace `plus90/lib/main.dart` with this package's `lib/main.dart`.
4. Run: `flutter run`

No backend, accounts, live scores, licensed team logos, or real fantasy scoring are connected yet.
Those are separate implementation stages requiring backend configuration and licensed data sources.
